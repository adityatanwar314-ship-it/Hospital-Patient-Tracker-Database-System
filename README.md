# Hospital Patient Tracker Database System

## Overview

This project is a Hospital Patient Tracker Database developed using MySQL. The system is designed to manage patient records, doctor information and appointment details.

## Objectives

* Maintain patient records
* Manage doctor information
* Track appointments
* Demonstrate database relationships using SQL

## Tools Used

* MySQL
* MySQL Workbench
* GitHub

## Database Tables

### Patients

Stores patient information.

### Doctors

Stores doctor details and specialization.

### Appointments

Maintains appointment and diagnosis records.

## Features Implemented

* Table creation
* Data insertion
* Primary Keys
* Foreign Keys
* SQL Joins
* Aggregate Queries
* SQL View

## Sample Queries

* Display all patients
* Display all doctors
* View appointment details
* Count doctors by specialization
